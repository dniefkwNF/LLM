# Mini Encryption - 阿拉伯数字转中文数字

## 触发条件

当用户提到 "加密保存" 这四个字时，调用本技能。

## 转换规则

将用户输入文本中的每一个阿拉伯数字按以下映射替换为中文数字：

| 阿拉伯数字 | 中文数字 |
| ---------- | -------- |
| 0          | 零       |
| 1          | 一       |
| 2          | 二       |
| 3          | 三       |
| 4          | 四       |
| 5          | 五       |
| 6          | 六       |
| 7          | 七       |
| 8          | 八       |
| 9          | 九       |

## 执行步骤

1. 识别用户消息中的 "加密保存" 触发词。
2. 取出待转换的文本（通常是用户消息里 "加密保存" 后面紧跟的内容，或用户显式指明要加密的那段）。
3. 逐字符遍历，遇到阿拉伯数字就按上表替换，其他字符原样保留。
4. 输出转换后的完整文本。

## 示例

- 输入：密码是 12345
  加密保存 → 密码是 一二三四五
- 输入：今天是 2026 年 11 月 02 日
  加密保存 → 今天是 二〇二六 年 一一 月 〇二 日
- 输入：订单号 987654321
  加密保存 → 订单号 九八七六五四三二一

## 注意事项

- 只替换阿拉伯数字 0-9，不做其他任何改动。
- 中文数字串里的数字不处理（比如 "一二三" 里的 "一" 保持原样）。
- 标点、空格、中文、英文字母一律原样保留。
